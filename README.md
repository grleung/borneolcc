These are the scripts associated with the following paper: "Deforestation Impacts on Clouds and Precipitation Over Borneo Vary Across the Diurnal Cycle"

Python analysis scripts should be run before the jupyter notebook for creating the final figures. The environment can be found under borneolcc.yml to see necessary packages. Most of the analysis scripts use dask (https://github.com/dask/dask), a package for parallelization of tasks. Scripts beginning with "tobac" also use the tobac package(https://github.com/tobac-project/tobac).

For any further questions about the code or data used in this study, please contact Gabrielle Leung (bee.leung@wisc.edu).
